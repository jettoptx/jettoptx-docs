## Welcome to OPTX

OPTX is a gaze-authenticated platform on Solana. This documentation teaches developers how to integrate with the Jett Optics ecosystem — from acquiring JTX access to anchoring attestations on-chain.

### Developer Quickstart

1. [Platform Access](/docs/getting-started/access) — acquire JTX and enter DOJO
2. [SDK Reference](/docs/sdk) — install `@jettoptx/auth`, `@jettoptx/chat`, augment registry
3. [AARON Client Integration](/docs/protocol/client-integration) — create session, verify gaze proof
4. [On-Chain Bridge](/docs/on-chain-bridge) — optional Solana attestation via poa-depin SDK
