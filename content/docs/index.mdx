## We Build Augments

An **Augment** is a digital extension of yourself. Not a skill. Not an application.

**OPTX Auth** is the who: *It's you* — Email, X, or wallet. Package [`@jettoptx/auth`](/docs/sdk/auth) for integrators.

**$JTX** is mainnet access when you need the live network. Deep operator addresses live under [Reference](/docs/reference) — not here.

Gaze vectors are processed on-device; only opaque proof hashes leave the device for attestation.
