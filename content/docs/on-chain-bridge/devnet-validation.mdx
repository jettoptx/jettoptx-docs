### Attestation Flow

1. **Gaze Capture** — On-device iris tracking classifies AGT tensors (COG/EMO/ENV)
2. **Proof Generation** — AARON router produces an opaque proof hash
3. **Verify** — `POST /verify` on the AARON router confirms the session
4. **On-Chain Submit** — Verified proofs anchor to the DePIN program via [jettoptx-poa-depin](https://github.com/jettoptx/jettoptx-poa-depin) SDK

### Running Against Devnet

```bash
git clone https://github.com/jettoptx/jettoptx-poa-depin.git
cd jettoptx-poa-depin
npm install
# Use devnet feature flag — see README for anchor test commands
anchor test -- --features devnet
```
