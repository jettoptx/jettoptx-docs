## End-to-end shape

OPTX runs from device and edge into optional Solana attestation:

1. Device gaze capture and local processing
2. Opaque proof hashes to AARON for verify
3. Optional on-chain bridge / DePIN programs

Gaze vectors are processed on-device; only opaque proof hashes leave the device for attestation.
