The OPTX / JettChat platform is split across two GitHub orgs. This page lists every **public** repository so readers know where to look.

- **`jettoptx`** — the umbrella org for OPTX, JettChat (xChat Native), AARON, JOE, and supporting infrastructure.
- **`Secure-Legion`** — the org for Phantom Mode (Tor + post-quantum messaging, patent pending) and its Tor patches.

Additional private repos back production services (xChat Native UI, E2E encryption SDK, JOE agentic core, and others) but are not listed here.

## `jettoptx` org

| Repo | Role |
|------|------|
| [`joe-docs`](https://github.com/jettoptx/joe-docs) | This documentation site (Next.js 16 + Fumadocs + MDX). Deployed at [jettoptx.dev/docs](https://jettoptx.dev/docs). |
| [`joe-jettauth-optx`](https://github.com/jettoptx/joe-jettauth-optx) | The published `@jettoptx/auth` SDK — X OAuth 2.0 PKCE + Solana `signMessage` + Ed25519 JWT. See [JETT Auth](/docs/authentication/jett-auth). |
| [`joe-aaron-router`](https://github.com/jettoptx/joe-aaron-router) | AARON gaze-verification router (FastAPI). Serves both JettChat modes. See [AARON Protocol](/docs/protocol). |
| [`joe-optx-hermes-api`](https://github.com/jettoptx/joe-optx-hermes-api) | FastAPI bridge for [Hermes Agent](https://github.com/NousResearch/hermes-agent), MPP pay-per-request. See [Hermes OPTX API](/docs/astrojoe/api). |
| [`joe-jtx-cstb-depin`](https://github.com/jettoptx/joe-jtx-cstb-depin) | Anchor program for $JTX/$CSTB compute-trust bonding on Solana. See [Token / JTX](/docs/token). |

## `Secure-Legion` org

| Repo | Role |
|------|------|
| [`Secure-Legion/android`](https://github.com/Secure-Legion/android) | **Phantom Mode** runtime — Tor private messaging app with post-quantum cryptography, private payments, metadata resistance. Patent pending. See [JettChat → Phantom Mode](/docs/jettchat/phantom-mode). |
| [`Secure-Legion/tor-hsservice-patched`](https://github.com/Secure-Legion/tor-hsservice-patched) | Fork of `tor-hsservice` 0.40 with intro-point exposure for OnionBalance coordination. Backs the **triple `.onion`** topology in Phantom Mode. |
| [`Secure-Legion/.github`](https://github.com/Secure-Legion) | Org profile. |
