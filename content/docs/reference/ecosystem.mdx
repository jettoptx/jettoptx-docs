The OPTX platform spans **16 repositories** in the `jettoptx` org plus **Secure-Legion** for Phantom Mode. This page maps each repo to its docs section and access level.

---

## Public Developer Surface

| Repo | Docs Section | Description |
|------|--------------|-------------|
| [jettoptx-docs](https://github.com/jettoptx/jettoptx-docs) | This site | Next.js 16 + Fumadocs + MDX at [jettoptx.dev](https://jettoptx.dev) |
| [jettoptx-sdk](https://github.com/jettoptx/jettoptx-sdk) | [SDK Reference](/docs/sdk) | **Canonical** — `@jettoptx/auth`, `@jettoptx/chat`, augment registry |
| [jettoptx-aaron-router](https://github.com/jettoptx/jettoptx-aaron-router) | [AARON Protocol](/docs/protocol) | FastAPI gaze attestation router + Python/TS SDKs |
| [jettoptx-aaron-public](https://github.com/jettoptx/jettoptx-aaron-public) | [Edge Gateway](/docs/infrastructure/edge-gateway) | Cloudflare edge — AARON routes + HEDGEHOG MCP |
| [jettoptx-poa-depin](https://github.com/jettoptx/jettoptx-poa-depin) | [On-Chain Bridge](/docs/on-chain-bridge) | Anchor programs (`jtx_cstb_trust`, `jett_vault`) + TS SDK |
| [jettoptx-jettchat-app](https://github.com/jettoptx/jettoptx-jettchat-app) | [JettChat](/docs/jettchat) | DOJO product at jettoptx.chat (integration patterns only) |
| [jettoptx-mojo](https://github.com/jettoptx/jettoptx-mojo) | [MOJO](/docs/dojo/mojo) | iOS first-gaze AGT attestation + handshake spec |
| [jettoptx-saas](https://github.com/jettoptx/jettoptx-saas) | [Platform Access](/docs/getting-started/access) | astroknots.space waitlist + JTX gate |
| [jettoptx-jtx-trade](https://github.com/jettoptx/jettoptx-jtx-trade) | [Trading & Mint](/docs/token/trading) | jtx.astroknots.space swap + NFT mint |
| [jettoptx-jettauth](https://github.com/jettoptx/jettoptx-jettauth) | [SDK / Auth](/docs/sdk/auth) | **Archived** → use jettoptx-sdk |
