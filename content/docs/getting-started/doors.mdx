## Three doors

| Door | Who | Where |
|------|-----|-------|
| **Human** | You getting an Augment | Mobile surface **MOJO** - see [DOJO / MOJO](/docs/dojo). Human door path reserved for when live; we do not link a dead CTA here. |
| **Agent** | Agents taking an Augment | [Hedgehog](/docs/astrojoe/hedgehog) agent porch (MCP). A 401 in the browser is expected - never treat MCP as a buyer landing. |
| **Builder** | Integrators | [SDK](/docs/sdk) / [OPTX Auth](/docs/sdk/auth) / [AARON](/docs/protocol) |

## Product words

- **Augment** - digital extension of yourself
- **MOJO** - mobile surface (not the Augment door name)
- **DOJO** - builder / operator surface
- **Hedgehog** - agent porch only
