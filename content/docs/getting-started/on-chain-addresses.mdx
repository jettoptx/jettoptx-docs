## Token Standards

- **$JTX v2** and **$OPTX** use **Token-2022 (SPL)** on mainnet/devnet respectively
- **$JTX v2** is the canonical governance + access gate token for [JettChat tiers](/docs/token/tiers)
- OPTX is **Solana-native**. See [On-Chain Bridge](/docs/on-chain-bridge) for program SDK usage.
