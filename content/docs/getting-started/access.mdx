## 1. Install the SDK

Install packages from the jettoptx-sdk monorepo: auth and chat.

## 2. OPTX Auth - Its you

Lead with recognition: Email, X, or wallet. See the Auth package under Build (SDK).

## 3. First verify

Use AARON client integration when you need attestation.

Gaze vectors are processed on-device; only opaque proof hashes leave the device for attestation.

## 4. Optional - mainnet access

JTX unlocks mainnet surfaces when ready. Mints and program IDs stay in Reference - not on this porch.
