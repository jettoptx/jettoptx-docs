The **JOE Agent API** is a FastAPI sidecar that extends the agent runtime with enhanced endpoints for JettChat. Open source under the jettoptx org.

## Why a Sidecar?

JettChat expects `/api/sessions`, `/api/skills`, `/api/memory`, `/api/config`, and SSE streaming chat endpoints. The JOE Agent API sits alongside the agent as a sidecar — extending capabilities without modifying the core.

## Key Endpoints

### SSE Streaming Chat

The primary integration point for JettChat. Sends a user message and streams the response as Server-Sent Events.

```bash
curl -N -X POST http://localhost:8643/api/sessions/{id}/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"message": "Tell me more"}'
```

### Gateway Status

At startup, the API probes the upstream agent and exposes detected capabilities at `/api/gateway-status` (high-level flags only — no admin wallet types or gaze storage capability dumps).

### Wallet

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/wallet/tempo/call` | Metered HEDGEHOG API call (pay-per-inference) |
| `GET` | `/api/wallet/tempo/usage` | Billing history and totals |
| `GET` | `/api/wallet/tempo/pricing` | Current pricing (authenticated) |

Exact OPTX margin and model SKUs are not listed on public docs.
