**JOE** (Jett Optics Engine) is the jOSH Operating Environment — the primary intelligent agent in the OPTX ecosystem. It runs on [Hermes Agent v0.17](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19) with Grok via the HEDGEHOG gateway, backed by SpacetimeDB for persistent memory and real-time state. JOE is **dual-instance**: a primary edge node (AARON + HEDGEHOG + SpacetimeDB) and a secondary containerized instance for redundancy. [jettoptx-hermes-api v0.4.0](/docs/astrojoe/api) bridges JettChat SSE, task orchestration, and Tempo billing to the native Hermes gateway.

## What AstroJOE Does

| Capability | Service | Description |
|-----------|---------|-------------|
| **SSE Streaming Chat** | [hermes-optx-api](/docs/astrojoe/api) | JettChat SSE envelope → Hermes `/api/sessions/*/chat/stream` |
| **Async agent runs** | Hermes gateway | `/v1/runs` + lifecycle SSE (v0.17+) |
| **Task Orchestration** | [hermes-optx-api](/docs/astrojoe/api) | Create, claim, execute, complete tasks with DAG workflows |
| **Tempo Billing** | [hermes-optx-api](/docs/astrojoe/api) | Metered HEDGEHOG API calls, escrow, on-chain wallet |
| **Memory** | SpacetimeDB | Persistent memory with categories, importance scoring, and full-text search |
| **Gaze Verification** | AARON Router | Manage gaze sessions, analyze AGT tensors (COG/EMO/ENV) |
| **Web Search** | HEDGEHOG | Search web and X/Twitter via Grok 4.20 multi-agent |
| **Messaging** | Federation transport | Optional Matrix-compatible inter-agent communication |
| **Swarm Coordination** | [hermes-optx-api](/docs/astrojoe/api) | Decompose goals into parallel/sequential/DAG subtasks |

> AstroJOE uses Hermes Agent's [Skills Hub](https://hermes-agent.nousresearch.com/docs/) and custom `SKILL.md` files under `~/.hermes/skills/`. Skill count grows with upstream releases — see [Skills](/docs/astrojoe/skills).
