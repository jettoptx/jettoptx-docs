**JOE** (Jett Optics Engine) is the jOSH Operating Environment — the primary intelligent agent in the OPTX ecosystem. It runs with Grok via the HEDGEHOG gateway, backed by SpacetimeDB for persistent memory and real-time state. JOE is **dual-instance**: a primary edge node (AARON + HEDGEHOG + SpacetimeDB) and a secondary containerized instance for redundancy. The [JOE Agent API](/docs/astrojoe/api) bridges JettChat SSE, task orchestration, and metered billing.

## What AstroJOE Does

| Capability | Service | Description |
|-----------|---------|-------------|
| **SSE Streaming Chat** | [JOE Agent API](/docs/astrojoe/api) | JettChat SSE envelope → session chat stream |
| **Async agent runs** | Agent gateway | `/v1/runs` + lifecycle SSE |
| **Task Orchestration** | [JOE Agent API](/docs/astrojoe/api) | Create, claim, execute, complete tasks with DAG workflows |
| **Metered Billing** | [JOE Agent API](/docs/astrojoe/api) | Metered HEDGEHOG API calls, escrow, on-chain wallet |
| **Memory** | SpacetimeDB | Persistent memory with categories, importance scoring, and full-text search |
| **Gaze Verification** | AARON Router | Manage gaze sessions, analyze AGT tensors (COG/EMO/ENV) |
| **Web Search** | HEDGEHOG | Search web and X/Twitter via Grok multi-agent |
| **Messaging** | Federation transport | Optional Matrix-compatible inter-agent communication |
| **Swarm Coordination** | [JOE Agent API](/docs/astrojoe/api) | Decompose goals into parallel/sequential/DAG subtasks |

> AstroJOE uses a Skills Hub and custom `SKILL.md` files. Skill count grows with releases — see [Skills](/docs/astrojoe/skills).
