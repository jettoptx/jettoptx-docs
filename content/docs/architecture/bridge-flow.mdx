## Solana-Native Attestation Flow

OPTX is **Solana-native**. Gaze proofs verified by the AARON router are bridged to on-chain attestation PDAs via the PoA DePIN program (`jtx_optx_devnet_poa_trustjoe`) — no cross-chain wrapping required.

<D2Diagram src="/diagrams/bridge-flow.svg" alt="Gaze to AARON to Solana attestation flow" caption="Solana Attestation Bridge Flow" />

| Stage | Component | Description |
|-------|-----------|-------------|
| **Capture** | Client (MOJO / Web) | On-device iris tracking → AGT classification |
| **Verify** | AARON Router | `POST /session` + `POST /verify` → opaque proof hash |
| **Record** | SpacetimeDB | Session state + attestation events at `stdb.jettoptics.ai` |
| **Anchor** | PoA DePIN | On-chain AGT attestation PDA on Solana mainnet |
| **Reward** | DePIN | PoA trust score + $OPTX / x402 micropayments |

## Pipeline Stages

### 1. Gaze Capture

- MediaPipe FaceLandmarker extracts iris landmarks on-device
- AGT tensors (COG/EMO/ENV) classified from gaze vectors
- Raw biometric data never leaves the device

### 2. AARON Verification

- Client submits opaque proof hash to `https://aaron.jettoptics.ai/verify`
- Router validates session nonce, hold durations, and confidence threshold
- Verified sessions emit SpacetimeDB events for agent workflows

### 3. On-Chain Attestation

- Bridge service submits attestation instruction to the PoA DePIN program
- Program ID (mainnet): `85sqs4upQiPrvk1NMuyfHVQoW1EGdgk8m2cQb7uMxXTF`
- See [jettoptx-poa-depin](https://github.com/jettoptx/jettoptx-poa-depin) SDK for integration

### 4. Vault & Staking

- **jett_vault** program: `JTX5uXTiZ1M3hJkjv5Cp5F8dr3Jc7nhJbQjCFmgEYA7`
- Staking and yield via [astroknots.space](https://astroknots.space) and [jtx.astroknots.space](https://jtx.astroknots.space)

## Retired Cross-Chain Paths

EVM (LayerZero) and XRPL (Wormhole) bridge pages were retired in v2.0.0. OPTX focuses on Solana mainnet for all production attestations. See [Changelog](/docs/reference/changelog).
