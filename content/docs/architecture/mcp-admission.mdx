AgenC inbound MCP stays fail-closed (`ADMISSION_IDENTITY_REQUIRED`) until the session is bound to a native OPTX identity. Environment keys and a static `MCP_API_KEY` are not that identity.

**JTX token-hold is not the admission ticket.** Holding ≥1 JTX is a legacy Wealth-08 billing path. MCP entry is Jett Auth (X + `signMessage`) plus an AARON session, proven on-chain by PoA `finalize_attestation`. Stripe / Space Cowboy NFT remain optional billing, not this kernel.

## Proof ladder

| MCP class | Required proof | AARON type |
|---|---|---|
| Unbound session | none → `tools/list` empty | — |
| Read (resources / prompts) | Jett Auth JWT + live AARON session | `login` |
| Mutate (files / shell) | `approve_action` verified or PoA `finalize_attestation` (entropy ≥ 750) | `approve_action` |
| LIVE spend / policy | MOJO QR, wait `verified` | `approve_action` |
| Solana tx | unsigned tx on phone | `sign_tx` |

## Public vs private

- **Public:** [jettoptx-aaron-public](https://github.com/jettoptx/jettoptx-aaron-public) (edge + introspect), [jettoptx-poa-depin](https://github.com/jettoptx/jettoptx-poa-depin) (chain), [jettoptx-docs](https://github.com/jettoptx/jettoptx-docs) (this page), [jettoptx-xwealth](https://github.com/jettoptx/jettoptx-xwealth) (QR mint).
- **Private:** Jett Auth JWT signing, AARON origin verify, daemon `bindAdmission`.
- Daemon port `7766` stays loopback. Agentgateway may terminate JWT at the cluster edge; it does not replace admission.
