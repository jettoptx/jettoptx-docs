**JETT Auth** is the unified authentication layer behind JettChat.

## Two Products, Two Auth Paths

| Surface | Auth Provider | When to Use |
|---------|---------------|-------------|
| **DOJO** ([jettoptx.chat](https://jettoptx.chat)) | **Privy** + JTX gate | End users accessing the DOJO product |
| **Custom integrations** | **`@jettoptx/auth`** from [jettoptx-sdk](/docs/sdk/auth) | Developers building xChat Native clients |

The standalone [jettoptx-jettauth](https://github.com/jettoptx/jettoptx-jettauth) repo is **archived** — install from the SDK monorepo instead.

## Two Chat Modes

|  | xChat Native | Phantom Mode |
|---|---|---|
| Login | Privy / X OAuth (integrators) | Jett Hub visual SSO + JTX gate |
| Biometric | AGT Gaze Triad (COG/EMO/ENV) | AGT Gaze Triad + Ping-Pong wake |
| Session | Ed25519 JWT (integrators) | PQC-wrapped session, hardware-bound |
| Wipe trigger | Standard logout | Duress PIN → cryptographic wipe |
| SDK | [`@jettoptx/auth`](/docs/sdk/auth) | [Secure-Legion/android](https://github.com/Secure-Legion/android) |

Both modes verify gaze through the same [AGT pipeline](/docs/authentication/gaze).

## Access Flow (JETT Hub)

After sign-in, the user must pass the **JTX gate** — typically by holding ≥1 JTX v2 on a connected wallet. Wallet-less paths (Stripe, Tempo CLI) are handled on [astroknots.space/stake](https://astroknots.space/stake).

Higher tiers unlock additional features via the same tier codes (`mojo`, `dojo`, `spaceCowboy`). See [Access Tiers](/docs/token/tiers) for balance thresholds and verification — not USD pricing.

## xChat Native (Integrators)

For custom apps outside DOJO, use `@jettoptx/auth`:

- X/Twitter OAuth 2.0 PKCE
- Solana `signMessage` wallet proof
- Ed25519 JWT in `jettauth` httpOnly cookie

See [SDK / Auth](/docs/sdk/auth) for install and quickstart.

## Phantom Mode specifics

Phantom Mode adds a Tor-only path with post-quantum hybrid encryption and hardware-backed keys. The Jett Hub visual SSO replaces OAuth — no third-party identity provider is contacted.

Implementation: [Secure-Legion/android](https://github.com/Secure-Legion/android) (patent pending).
