Developer docs describe **how** tier access is enforced, not **what** each tier costs in USD.

## Where pricing lives

Checkout, feature comparison, and monthly billing amounts are maintained on the product site:

**[astroknots.space/stake](https://astroknots.space/stake)**

## What integrators need

- Subscription status (Stripe or Tempo CLI) maps to the same tier codes as JTX balance — see [Access Tiers](/docs/token/tiers)
- Base entry still requires passing the JTX gate (≥1 JTX) **or** an active wallet-less subscription entitlement, depending on product surface
- Do not hardcode dollar amounts in client apps — query subscription state server-side or link users to astroknots.space
