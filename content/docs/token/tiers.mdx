## Subscription tiers

Tiers are accessible by **Stripe subscription** (fiat) or by holding JTX at market price.
JTX has **no fixed dollar peg** — its price floats freely on open markets.

| Tier | Subscription | JTX threshold | Headline unlocks |
|------|-------------|---------------|-------------------|
| **MOJO** *(Starter)* | $8.88 / mo | 12 JTX | Gaze auth (OPT𝕏), JetChat + custom emoji keyboard, limited OPTX earning, shared AI assistant |
| **DOJO** *(Popular)* | $28.88 / mo | 444 JTX | 1 Hermes agent container (4 vCPU / 16 GB), 1.5M Grok output tokens/mo |
| **SPACE COWBOY** *(Legendary)* | $88.88 / mo | 1,111 JTX | 3 Hermes containers, 8M Grok output tokens/mo, developer tools, governance voting |

> **Space Cowboy NFT** — Alternatively, burn 1,111 JTX to mint a Space Cowboy NFT for **lifetime** access. Only 1,111 will ever exist. [Learn more →](/docs/token)

## Code-level enforcement

JettChat's middleware checks tier access via Stripe subscription status **or** Space Cowboy NFT ownership:

| Code tier | Access method |
|-----------|--------------|
| `mojo` | Active Stripe MOJO subscription |
| `dojo` | Active Stripe DOJO subscription |
| `spaceCowboy` | Active Stripe SPACE COWBOY subscription **or** Space Cowboy NFT in wallet |
