**$JTX v2** is the canonical JettChat governance and access token on **Solana mainnet**:

```
JTXGnx83s2QZ2MwYkRD1cBKrqQKSdG5oe8vSYW5Zjoe
```

Token-2022, 9 decimals. Legacy v1 (`9XpJiKEY…`) has revoked mint authority — see [Trading & Mint](/docs/token/trading) for migration.

## What JTX does

- **DOJO access** — Hold ≥1 JTX v2 to enter [jettoptx.chat](https://jettoptx.chat)
- **Tier staking** — MOJO / DOJO / SPACE COWBOY via [Tiers](/docs/token/tiers)
- **Space Cowboy NFT** — Mint via [jtx.astroknots.space/mint](https://jtx.astroknots.space/mint)
- **Governance** — Space Cowboy NFT holders vote on protocol direction
- **Trading** — Freely tradeable on Jupiter / Meteora

## Subscription tiers (fiat)

Wallet-less access via **Stripe** ($8.88 / $28.88 / $88.88 per month). See [Subscriptions](/docs/token/subscriptions).
