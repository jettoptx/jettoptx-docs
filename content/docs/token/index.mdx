**$JTX v2** is the canonical JettChat governance and access token on **Solana mainnet**:

```
JTXGnx83s2QZ2MwYkRD1cBKrqQKSdG5oe8vSYW5Zjoe
```

Token-2022, 9 decimals. Legacy v1 (`9XpJiKEY…`) has revoked mint authority — see [Trading & Mint](/docs/token/trading) for migration.

## What JTX does

- **DOJO entry** — Hold ≥1 JTX v2 to pass the [Platform Access](/docs/getting-started/access) gate at [jettoptx.chat](https://jettoptx.chat)
- **Space Cowboy NFT** — On-chain lifetime access via [jtx.astroknots.space/mint](https://jtx.astroknots.space/mint)
- **Governance** — Space Cowboy NFT holders vote on protocol direction
- **Trading** — Freely tradeable on Jupiter / Meteora

Checkout and live pricing live on **[astroknots.space/stake](https://astroknots.space/stake)** — not duplicated here.
