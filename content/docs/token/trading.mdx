The **[jettoptx-jtx-trade](https://github.com/jettoptx/jettoptx-jtx-trade)** app is the public Solana surface. This docs site’s house links use [space.jettoptics.si](https://space.jettoptics.si). [jtx.astroknots.space](https://jtx.astroknots.space) serves the same app title (checked 2026-11-20).

Route table below is `src/App.tsx` on `main`. Constants are `src/lib/programConstants.ts` and `src/lib/collectionConfig.ts`.

## SJTX vs $JTX v2

`/buy` and `/stonk` are **StonkJTX (SJTX)**, a StonkFun community token quoted in JTO. The governance mint stays **$JTX v2**.

| Item | Value |
|------|--------|
| SJTX mint | `6zmDH3opJ1tekeFhfLaMWN1aMR9aNL3MYRUXYu4qTxr7` |
| StonkFun | `https://www.stonkfun.xyz/token/6zmDH3opJ1tekeFhfLaMWN1aMR9aNL3MYRUXYu4qTxr7` |
| View chart (`StonkFlywheel`) | `https://app.jtx.com/?mint=6zmDH3opJ1tekeFhfLaMWN1aMR9aNL3MYRUXYu4qTxr7` |
| `JTX_TRADE` / `JTX_TRADE_SJTX` | `https://app.jtx.com/ref/Jett` |

**Chart pitfall.** “View chart” on `/stonk` includes the SJTX mint query. Buttons that use `JTX_TRADE` (the “Trade on JTX” link on `/buy`, and “Trade JTX” on `StonkMemePanel`) open `https://app.jtx.com/ref/Jett` with **no** `mint` query, so they do not land on the SJTX chart.

The `/stonk` footer states $SJTX has no intrinsic value and is not investment advice. These docs do not add a return claim.

## Local development

```bash
git clone https://github.com/jettoptx/jettoptx-jtx-trade.git
cd jettoptx-jtx-trade
npm install --legacy-peer-deps
cp .env.example .env.local
npm run dev
# http://localhost:5173
```

Set `VITE_SOLANA_RPC_URL` and `VITE_PRIVY_APP_ID` (`VITE_PRIVY_CLIENT_ID` when the Privy app uses an app client). Allowlist `localhost` and the deployed hosts in the Privy dashboard, and enable Solana embedded wallets.

**Local gallery pitfall.** The dev RPC fallback is a public node without DAS, so a collection read shows 0 NFTs. Production uses the keyless Helius Secure URL.

Stack: Vite, Ionic React 8, Capacitor, React 19, `react-router` v6, Privy, Metaplex Core (`mpl-core`).
