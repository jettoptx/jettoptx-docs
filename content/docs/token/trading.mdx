The **[jettoptx-jtx-trade](https://github.com/jettoptx/jettoptx-jtx-trade)** app is the public Solana builder UI at [jtx.astroknots.space](https://jtx.astroknots.space).

## Features

| Route | Feature |
|-------|---------|
| `/` | $JTX swap via Jupiter aggregator |
| `/mint` | Space Cowboys NFT mint (1,111 supply) |
| `/collection` | Minted NFT gallery |
| `/admin/deploy` | LP bootstrap (deploy wallet gated) |

## v1 → v2 Migration

Legacy v1 JTX holders should follow the migration runbook in the repo:

[jtx-v2-migration-runbook.md](https://github.com/jettoptx/jettoptx-jtx-trade/blob/main/docs/jtx-v2-migration-runbook.md)

## Development

```bash
git clone https://github.com/jettoptx/jettoptx-jtx-trade.git
cd jettoptx-jtx-trade
npm install --legacy-peer-deps
cp .env.example .env.local
npm run dev
```

Stack: Vite + React 19, Anchor 0.30, Metaplex Core, Meteora DLMM.
